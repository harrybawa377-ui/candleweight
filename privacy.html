Privacy Policy

Last Updated: September 1, 2025

1. Introduction

Welcome to Candle weight. We value your privacy and are committed to protecting any information collected through our web platform, APIs, WebSocket data streams, and analytics tools. This Privacy Policy explains how we collect, use, and safeguard your data when you visit our site.

2. Information We Collect

We keep data collection minimal to ensure fast performance and maximum user privacy:

  • Log & Usage Data: Standard server logs, including IP addresses, browser types, landing/exit pages, and timestamps for performance monitoring and security auditing.
  • WebSocket Stream Data: Market depth data and public price metrics transmitted via our WebSocket connections. We do not inspect or read private desktop trading activities or local files.

3. How We Use Your Information

Any technical data collected is strictly utilized for operational efficiency:

  • To deliver sub-second data streaming and chart synchronization.
  • To maintain server stability, prevent abuse, and mitigate DDoS risks.
  • To optimize user dashboard interface layouts across desktop and mobile devices.

4. Data Security

We implement industry-standard encryption protocols (HTTPS and Secure WebSockets/WSS) to safeguard network transmissions. However, no data transmission over the internet can be guaranteed to be 100% secure, so we advise users to exercise standard security practices on local client systems.
