Understanding the Live Nifty 50 Weightage Table

The CandleWeight Live Terminal provides a real-time breakdown of Nifty 50 stock weightage momentum. By tracking short-term order flow fluctuations against historical baselines, this table highlights institutional buy and sell pressure across all Nifty 50 constituents as it happens.

Column Breakdown & Calculation Logic

  • Column 1: Last 5 Minutes Nifty Weight Contribution
    Measures the cumulative weight contribution of each stock over the rolling 5-minute window.
  • Column 2: Last 1 Minute Nifty Weight Contribution
    Displays the instant 1-minute weight score generated by the latest tick data.
  • Column 3: Today's Running 1-Minute Average Weight
    Calculates the cumulative moving average of all 1-minute weight scores logged since market open today.
  • Column 4: 5-Day Historical Same-Minute Average (Comparison Baseline)
    Computes the 5-day historical average weight score for the exact same minute of the trading day.
  • Column 5: Cumulative Time Stamp (Till Now)
    Logs the exact elapsed time and timestamp for the session.
